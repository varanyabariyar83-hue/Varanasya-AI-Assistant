☁️ Deploy via GitHub → Cloudflare Pages

Single file, no build step. Push to GitHub → auto-deploys to Cloudflare. Free forever.

  • 1
    Get your free Groq API key
    Go to console.groq.com → Sign up free → API Keys → Create Key. No credit card needed.
  • 2
    Paste key in the app header
    Enter your key in the box at the top → Save Key. It saves in your browser for personal use.
  • 3
    Push to GitHub
    Create a repo at github.com/new, name it varanasya-ai, upload index.html.
  • 4
    Connect to Cloudflare Pages
    dash.cloudflare.com → Workers & Pages → Pages → Create → Connect to Git → select repo → Framework: None, Build command: empty, Output: / → Deploy.
  • 5
    Share the link 🎉
    Your app is live at https://varanasya-ai.pages.dev. Each user pastes their own free Groq key — takes 2 minutes and it's free for everyone.
